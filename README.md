# Portafolio de Desarrollo y Estructuras de Datos 💻

Bienvenido a mi repositorio de proyectos de software. Aquí recopilo implementaciones prácticas de estructuras de datos, programación orientada a objetos (POO) y algoritmos numéricos desarrollados durante mi formación en la Licenciatura en Matemáticas Aplicadas y Computación.

El objetivo de este repositorio es demostrar mis fundamentos de programación, pensamiento lógico y manejo de lenguajes compilados de manera eficiente.

## 🛠️ Tecnologías y Lenguajes Utilizados
* **Lenguajes:** C, C++, Java
* **Conceptos clave:** Estructuras de Datos, Gestión Dinámica de Memoria, Programación Orientada a Objetos (POO), Algoritmos Matemáticos, Modelado UML.

---

## 📂 Estructura del Repositorio

### 1. Estructuras de Datos (C)
Esta sección contiene la implementación manual de diversas estructuras de datos desde cero, demostrando un dominio profundo de los punteros y la gestión de memoria dinámica (`malloc` / `free`).
* **Listas Enlazadas:** Creación, recorrido, búsqueda y eliminación de nodos en listas simples.
* **Listas Doblemente Enlazadas y Circulares:** Implementación de nodos con múltiples referencias y algoritmos para iteraciones cíclicas.
* **Inserción Ordenada:** Algoritmos para insertar datos manteniendo el ordenamiento de la estructura en tiempo de ejecución.
* **Pilas (Stacks):** Uso de estructuras LIFO para el análisis sintáctico y balanceo correcto de expresiones matemáticas (paréntesis, llaves y corchetes).

### 2. Programación Orientada a Objetos (Java)
Proyectos enfocados en la arquitectura de software y simulación de sistemas empresariales basándose en diagramas UML.
* **Sistema de Facturación:** Implementación de clases para el procesamiento y registro de facturas, aplicando principios de encapsulamiento y cohesión.
* **Gestión de Operaciones en Cajas:** Simulador diseñado para gestionar de manera segura flujos de operaciones utilizando herencia y polimorfismo.

### 3. Métodos Numéricos (C++)
Aplicación de la programación para la resolución de modelos matemáticos y científicos.
* Algoritmos de cálculo intensivo para aproximaciones numéricas.
* Documentación y exportación de datos para su posterior graficación y análisis.

## 🚀 Cómo ejecutar los proyectos

**Para los programas en C / C++:**
Puedes compilar el código fuente utilizando GCC en tu terminal:
```bash
# Ejemplo para compilar un archivo en C
gcc 7.c -o programa_listas
./programa_listas

```

**Para los programas en Java:**
Asegúrate de tener instalado el JDK y compila desde la terminal:

```bash
# Ejemplo para compilar y ejecutar Java
javac factura.java
java factura

```
